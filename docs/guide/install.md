# Install

1. Download `meshwright-<version>.zip` from the
   [releases](https://github.com/stritti/meshwright/releases).
2. In SolidCraft, open **Preferences › Plugins › Install plugin…** (also *File › Plugins…*) and
   pick the zip.

meshwright is tested against SolidCraft 0.45. SolidCraft's plugin support is experimental, so a
newer SolidCraft release may need a newer meshwright.

To build the plugin yourself, see [Development](/development) and the
[README](https://github.com/stritti/meshwright#build-from-source).

Next: [use it](/guide/use).
